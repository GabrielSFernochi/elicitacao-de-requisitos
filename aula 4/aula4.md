[VENDEDORES DEVEM ACESSAR O SISTEMA PARA REGISTAR PEDIDOS]
* Requisito: O sistema deve permitir a troca rápida de vendedores com no máximo duas etapas de segurança para calcular com exatidão as taxas de comissão mensais
fonte 1: Entrevista presencial com vendedor, fonte humana, nivel operacional
fonte 2: Entrevista com o supervisor geral de vendas, fonte humana, nivel tatico
[O ADMINISTRADOR PARA CADASTRAR E REMOVER PRODUTOS]
* Requisito: O sistema deve atualizar o catalogo de produtos a cada 5 minutos sempre que o equipamento do vendedor se conectar a alguma rede
fonte 1: Funcionalidade já existente, fonte não humana, sistema legado
fonte 2: Documento válido para a versão atual, fonte não humana, documentação
[O TIME DE ESTOQUE PARA CONTROLAR A QUANTIDADE DISPONÍVEL]
* Requisito: O sistema de contagem de estoque se atualiza a cada 30 segundos e reserva a quantidade de itens que serão vendidos por 15 minutos até a conclusão da venda
fonte 1: Entrevista com o chefe de estoque, fonte humana, nivel tático
fonte 2: Parágrafo sobre atualização de estoque, fonte não humana, documentação
